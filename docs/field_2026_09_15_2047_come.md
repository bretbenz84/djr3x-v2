## Changes

The shared Mac approach controller separates personal stand-off from obstacle
clearance. Valid independent radial readings retain the requested personal
stand-off plus 10 cm. Fused front readings, including the matrix, retain a
55 cm obstacle envelope, with braking-distance and latency margins applied
before reaching it. When fused range is inside personal stand-off but independent
range allows progress, speed is capped at 0.10 m/s. If independent range is
unavailable, the full conservative stand-off still applies to fused range.
Camera arrival, telemetry/camera freshness, firmware obstruction stops, bounded
travel, and the no-creep settling latch remain active.

This is not a sensor recalibration or a claim that every matrix return is false.
It permits cautious progress in the recorded disagreement without discarding
either sensor stream. Independent range is still a conservative limit, not proof
that its target is the caller. The physically faulty right radial remains a
coverage limitation.

The approach whir starts only when telemetry reports linear movement above
0.02 m/s and stops when movement stops. Launching a zero-velocity approach no
longer starts the sound. Retry eligibility now requires fresh measured clearance
with 40 cm of remaining margin sustained for 0.6 seconds, in addition to the
existing attempt gap and limit. Idle base state alone cannot trigger a retry.
If clearance does not recover, the existing bounded wait explains the hold and
ends the request instead of silently looping.
